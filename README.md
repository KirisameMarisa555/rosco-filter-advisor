# Rosco Filter Advisor

Rosco 色片建议工具，用于根据两个光源色温计算 Mired Shift，并推荐接近目标偏移量的 Rosco 色温校正色片。  
Rosco Filter Advisor calculates the Mired Shift between two color temperatures and recommends matching Rosco correction filters.
